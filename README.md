# Dechator

실시간 채팅 데이터를 수집·분석하여 의미 있는 정보로 재구성하는 백엔드 시스템입니다.

## 주요 기능
- 다양한 채팅 플랫폼 연동 및 데이터 수집
- 데이터 전처리 및 의미 분석 로직 구현
- RESTful API로 가공 데이터 제공
- 사용자/채널별 통계 및 대시보드

## 기술 스택
- Java, Spring Boot, JPA
- REST API, MySQL, Docker

## 프로젝트 구조
- 데이터 수집기와 분석기 모듈 분리 설계
- 비동기 처리 및 트랜잭션 관리
- DB 모델링 및 쿼리 최적화

## 실행 방법
```bash
./gradlew bootRun
```
